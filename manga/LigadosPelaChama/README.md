## Princípios de continuidade

- Decisões marcadas como **estabelecidas** fazem parte da continuidade atual.
- Elementos marcados como **provisórios** podem ser renomeados ou alterados.
- Ideias marcadas como **gancho** ainda não são fatos confirmados do mundo.

## Direção atual

Quadrinho shōnen colorido de aventura e fantasia medieval com alta magia, mistério cósmico, conflitos políticos e laços de amizade.

## Organização dos capítulos

Cada capítulo possui roteiro geral, continuidade local, um Markdown para cada página e pastas separadas para storyboards, painéis e páginas finalizadas.
